# Libft

A C library with my own versions of standard functions and later added extras that I have found to be useful in many projects. I will be updating the existing functions and adding new ones as my studies continue and new projects will be conducted.

## Install

```
git clone git@github.com:svolain/libft.git
cd libft
make
```

## Goals of the project

This is my first project as a student at 42 network. The ultimate goal of recoding the already existing C standard library functions is understanding the way these functions work, implementing and learning to use them, as well as learning the C syntax. This library has been used in almost all C projects during my 42 studies instead of using external C-libraries.
